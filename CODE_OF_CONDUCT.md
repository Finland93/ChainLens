# Code of Conduct

## Our Mission

ChainLens exists to make crypto safer. Everyone contributing to this project shares that goal.

## Rules

1. **Be respectful.** Disagree with ideas, not people.
2. **Be constructive.** Criticism is welcome if it includes a suggestion for improvement.
3. **No spam or self-promotion.** Don't use issues/discussions to promote your token or project.
4. **No scam assistance.** Don't submit PRs that weaken detection, create bypass methods, or help scammers evade analysis. This will result in an immediate ban.
5. **Assume good intent.** Most people are here to help.

## Enforcement

Violations will be addressed by maintainers. Repeated violations result in being blocked from the repository.

## Scope

This code of conduct applies to all ChainLens spaces: GitHub issues, pull requests, discussions, and social media.
